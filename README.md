# Retail Sales Analysis Project

## Project Overview
This project focuses on analyzing retail sales data to gain insights into customer behavior, product performance, and sales trends. The dataset contains transaction-level information, including customer demographics and purchase details.

## Dataset Description

| Column Name | Description | Data Type |
| :--- | :--- | :--- |
| **Transaction ID** | A unique identifier for each transaction. | Integer |
| **Date** | The date the transaction occurred. | Date/Object |
| **Customer ID** | A unique identifier for each customer. | Object |
| **Gender** | Gender of the customer (e.g., Male, Female). | Object |
| **Age** | Age of the customer at the time of purchase. | Integer |
| **Product Category** | The category of the product purchased (e.g., Electronics, Clothing, Beauty). | Object |
| **Quantity** | The number of units purchased in the transaction. | Integer |
| **Price per Unit** | The cost of a single unit of the product. | Integer |
| **Total Amount** | The total revenue generated from the transaction (Quantity * Price per Unit). | Integer |

## Key Objectives
- **Exploratory Data Analysis (EDA):** Identify distributions, correlations, and basic statistics.
- **Customer Segmentation:** Analyze sales by gender and age groups.
- **Product Performance:** Determine which categories generate the most revenue and have the highest sales volume.
- **Time-Series Analysis:** Explore sales trends over time to identify seasonal patterns.

## Usage
1. Clone the repository.
2.Run the analysis notebooks or scripts to generate insights.
